# 🧠 BASkill-Claude
### IT Business Analyst Skill for Claude · Insurance & Financial Services Edition

A comprehensive Claude skill plugin for IT Business Analysis, purpose-built for **insurance, reinsurance, and financial services**. Works across life & health, P&C, London Market, and reinsurance programmes.

---

## ⚡ Quick Install

1. Download **[it-business-analyst-plugin.zip](./it-business-analyst-plugin.zip)**
2. In Claude.ai → **Customize → Skills → "+" → Upload**
3. Upload the ZIP — the skill activates automatically

> **Requirements:** Claude Pro, Team, or Enterprise plan · Code execution enabled in Settings

---

## 🎯 What It Does

Just describe what you need in plain English — the skill triggers automatically:

| Say something like... | You get... |
|---|---|
| *"Write user stories for the claims automation project"* | Epics, themes & stories with INVEST criteria + acceptance criteria |
| *"Create a RACI for the underwriting transformation"* | Stakeholder RACI matrix with insurance roles pre-populated |
| *"Build a data dictionary for the policy admin system"* | Field catalogue with data types, rules & source-to-target mapping |
| *"Assess regulatory impact of AI-assisted underwriting"* | Solvency II, IDD, GDPR & FCA Consumer Duty checklist |
| *"Here's the workshop transcript — extract requirements"* | Structured BRD with traceability IDs, decisions & open questions |
| *"Draft a steering committee update for Sprint 5"* | Polished status update with RAG indicators |

## 📦 What's Included

### Core BA Deliverables
- **Requirements docs** — BRD, FRD, user stories, epics & themes with acceptance criteria
- **Process flows** — Interactive HTML workflow diagrams (presentation-ready) + Mermaid for inline use
- **Stakeholder management** — RACI matrices, power-interest grids, communication plans
- **Gap analysis** — Current vs future state mapping, change delta documentation

### Data & Traceability
- **Data dictionary & source-to-target mapping** — Field catalogues with transformation rules
- **Requirements Traceability Matrix (RTM)** — Forward, backward & regulatory traceability

### Source Ingestion (paste & go)
- **Existing docs** — Functional specs, prior BRDs, design documents
- **Call transcripts** — Mine stakeholder interviews for requirements & contradictions
- **Wiki pages & PRDs** — Decompose into epics and stories with traceability

### Practical BA Tools
- **Estimation** — Story points, T-shirt sizing with insurance-specific complexity multipliers
- **Stakeholder comms** — Status updates, change requests, steering briefs, escalation emails
- **Regulatory checklists** — Solvency II · IDD · GDPR · FCA Consumer Duty · Lloyd's standards
- **Glossary manager** — Auto-generates glossaries with 60+ insurance domain terms built in

### Cross-Cutting (automatic on every output)
- ✅ Glossary auto-generation
- ✅ Regulatory impact scanning on change-related deliverables
- ✅ Estimation readiness indicators on stories
- ✅ Traceability IDs on all requirements
